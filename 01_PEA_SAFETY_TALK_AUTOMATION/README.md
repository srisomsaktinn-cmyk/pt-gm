# 🏢 PEA Safety Talk & Participant Automation System
**Domain:** Enterprise Document Automation & Data Processing  
**Description:** Automates participant name matching, department classification, and document generation for PEA Safety Talk (Cybersecurity) events.

## Directory Structure:
- `scripts/`: Python scripts for document generation, position extraction, and department parsing.
- `input_data/`: Excel participant lists (`Participant.xlsx`), XML tables, and reference markdown files.
- `output_docs/`: Generated Microsoft Word `.docx` meeting documents.
- `analysis_logs/`: Text log dumps and branch breakdown reports.
